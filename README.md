# 대한민국 천만 관객 영화 흥행 기록 분석 앱

위키백과 **'대한민국의 영화 흥행 기록'** 문서에서 천만 관객 영화 표를 수집·정제하고 시각화하는 Streamlit 실습 앱입니다.

## 주요 기능

1. **웹 데이터 수집 (`fetch_html`)**: `requests`와 실습용 `User-Agent`, `timeout`을 적용해 위키백과 HTML을 가져오며 연결 실패·시간 초과·HTTP 오류를 처리합니다.
2. **표 탐색 및 각주 제거 (`find_target_table`, `parse_table_to_df`)**: `class="wikitable"` 표 중 첫 줄(`tr`)에 `'관객수'`와 `'감독'`이 모두 포함된 첫 번째 표를 찾고, 각주 번호(`sup` 태그)를 제거한 뒤 `DataFrame`으로 변환합니다.
3. **데이터 정제 (`clean_movie_data`)**:
   - 영화 제목에서 `《》` 기호 제거
   - 관객수를 숫자(`int`)로 변환
   - 개봉일에서 `개봉연도`와 `개봉월` 추출
4. **대시보드 시각화 (`render_dashboard`)**:
   - 천만 영화 수, 역대 1위, 1위 관객수 지표 표시
   - 인덱스 숨김 처리된 영화 표 출력
   - 관객수 상위 10편 가로 막대 차트
   - 개봉 연도별 영화 편수 막대 차트
